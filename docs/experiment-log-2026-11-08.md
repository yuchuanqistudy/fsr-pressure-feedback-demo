# 单点 FSR 压力感知与 LED 反馈实验

日期：2026-11-08

## 当前成果

用户已实际验证：Arduino 读取 FSR；Python 实时显示原始 ADC 和 EMA 曲线；滞回判断接触；CSV 与 PNG 保存；压力控制外接 LED 亮度；曲线与灯光同时工作。

振动反馈尚未实测。当前 LED 为 PWM 控制练习，不能视为振动反馈阶段完成。

## 器件

- ZYDUINO UNO 兼容板，照片主芯片标识 ATMEGA328P。
- 包装标识 FSR402B，两端式薄膜力敏电阻。
- FSR 分压固定电阻：1 kΩ（棕黑红金，目视辨认，无万用表复核）。
- 红色 LED；串联限流电阻：220 Ω（红红棕金，目视辨认）。
- 面包板、杜邦线、鳄鱼夹线、USB 数据线。

## 设计接线（依据教学步骤与用户确认）

FSR：5V → FSR → 信号节点 → 1 kΩ → GND；信号节点连接 A0。

面包板目标孔位：分压电阻 A10—A15，A0 接 C10，FSR 信号端接 D10，GND 接 B15。

LED：D3 → 220 Ω → LED 阳极 → LED 阴极 → GND。

面包板目标孔位：LED 长脚 A25、短脚 A26；电阻 B25—B30；D3 接 C30；B26 用跳线连接到 C15。

同一行 A～E 内部相通。这里是设计孔位，最终照片存在遮挡，不能将每个实际孔位视为已由照片独立确认。用户随后现场确认灰线连接 ~3（D3）；该项依据用户确认，而非照片独立辨认。用户已验证实际运行成功。

## 软件与参数

- Arduino 程序：04_fsr_led_feedback。
- Python 程序：fsr_live_record.py。
- macOS，VS Code，Miniconda base 环境；用户实测 pyserial 3.5 可用，已安装 Matplotlib。
- 实测串口：/dev/cu.usbserial-310；切换 USB 接口后名称可能变化。
- 串口波特率：115200。
- Arduino 循环末尾 delay(20)，约 50 次/秒，不是精确硬件定时。
- EMA：alpha = 0.2；以第一个有效读数初始化。
- 固定基线：0；response = max(0, EMA - baseline)。未实现自动基线校准。
- 接触进入：response >= 50；接触退出：response <= 20；中间保持状态。
- LED PWM：未接触为 0；接触时约为 response / 900 × 255，四舍五入并限制到 0～255。
- Arduino 发送原始 ADC；Arduino 与 Python 各自进行 EMA，Python 不对 Arduino 的 EMA 再滤波。

## 实测观察

- 初用 10 kΩ：轻按容易接近 1000，手指按压的可分辨范围不足。
- 换为 1 kΩ：用户报告轻按约 200，用力约 900，松手回到 0；不同手势下轻按也出现过 380～461，未进行标准力标定。
- 不接触观察约 10 秒：用户报告慢速和快速输出下均为 0。不能据此保证所有环境下无噪声。
- EMA 曲线较原始曲线圆滑，按下、松开均可见跟随延迟。
- 已检查的首次 CSV：2070 行，末条时间 41.834282 秒，ADC 为 0～918，时间顺序正常；记录三次进入和三次退出接触。
- 用户确认 LED 的独立 PWM 测试与压力到亮度的联动成功，随后确认 Python 曲线与 LED 可同时工作。

## 数据与时间的含义

ADC 和 response 为相对电信号读数，不是牛顿或帕斯卡。FSR 与分压电路均具有非线性，未标定前不能把读数视为力的线性度量。

CSV 保存电脑解析数据时的经过时间，不是 Arduino 精确采样时间；多条缓存数据可能在一次刷新中被处理。CSV 保存整次接收的有效数据，PNG 仅保存结束时最后约 10 秒的画面。

## 已解决的问题

- 换 Mac USB 接口后串口从 110 变为 310，需要重新选择端口。
- Resource busy：退出占用串口的 Arduino 监视器/绘图器，之后 Python 可连接。
- Python 代码误贴进终端：Control+C 取消未完成输入；代码保存到 .py 文件后再运行。
